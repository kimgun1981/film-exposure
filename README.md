# 필름 노출 계산기

필름카메라의 조리개·셔터속도·필름감도·ND필터로 적정노출을 계산하는 웹앱입니다.
한 번 설치하면 인터넷 없이 휴대폰에서 동작합니다.

**바로 열기: https://kimgun1981.github.io/film-exposure/**

## 설치 (처음 한 번)

- 아이폰: 사파리로 위 주소 열기 → 공유 버튼 → "홈 화면에 추가"
- 안드로이드: 크롬으로 열기 → 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"

설치한 뒤에는 비행기 모드에서도 열립니다. 새 버전이 나오면 앱 아래쪽에 "적용하기" 알림이 뜹니다.

## 주요 기능

- 장면 밝기 선택(써니16 기준) 또는 노출계 값(EV) 직접 입력
- 셔터 자동 / 조리개 자동 / 직접 확인(지금 조합이 몇 스톱 벗어났는지)
- 필름카메라 노출계와 같은 ⅓스톱 눈금 막대
- ND 필터 0~20스톱 (겹쳐 쓸 때는 스톱 수를 더해서 선택)
- 필름별 장노출(상반칙불궤) 보정 — 일포드·코닥·후지필름 공식 자료 기준
- 장노출 타이머 (끝나기 전 알림음, 화면 꺼짐 방지)
- 기본 / 햇빛 / 야간(빨강) 화면 모드

## 수록 필름

- 일포드·켄트미어 흑백 11종
- 코닥 흑백 3종 (Tri-X 400, T-MAX 100, T-MAX 400)
- 코닥 컬러 네거티브 7종 (Portra, Ektar, Gold, Ultramax, ColorPlus)
- 후지필름 8종 (Acros 100 II, C200, Superia X-TRA 400, Fujifilm 200·400, Velvia 50·100, Provia 100F)
- 기타 필름 · 일반 보정(근사값)

## 개발 메모

- 순수 HTML/CSS/JavaScript, 빌드 과정 없음. GitHub Pages로 배포합니다.
- 파일 구성: 계산 공식 `exposure.js` / 기준값·필름 자료 `data.js` / 화면 `app.js` / 타이머 `timer.js` / 오프라인 저장 `sw.js`
- 계산 검증: `npm test`
- 배포 전 버전 올리기: `npm run bump -- 1.0.5` (`app.js`와 `sw.js`를 함께 바꿉니다)
- 새 파일을 추가하면 `sw.js`의 `ASSETS` 목록에도 넣습니다. 빠지면 `npm test`가 알려줍니다.
- 자세한 설계와 변경 이력: [개발계획서.md](개발계획서.md)
