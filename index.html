    셔터 눈금

    필름카메라 셔터는 대부분 1스톱 눈금입니다 (1/60, 1/125, 1/250 …).

    화면 모드

    사용 방법

    1. 장면 밝기(날씨)를 고릅니다. 노출계가 있으면 EV를 직접 맞추세요.
    2. 필름을 고르면 감도(ISO)와 장노출 보정이 자동으로 맞춰집니다. 증감(푸시·풀)할 땐 ISO를 따로 바꾸세요.
    3. 위쪽 버튼으로 셔터·조리개 중 무엇을 자동 계산할지 고릅니다. "직접 확인"은 내가 맞춘 조합이 몇 스톱 벗어났는지 보여줍니다.
    4. ND 필터를 겹쳐 쓸 땐 스톱 수를 더해서 고르세요 (예: ND8 + ND64 = 9스톱).
    5. 네거티브 필름은 조금 밝게 찍혀도 괜찮지만, 슬라이드 필름은 ⅓스톱 차이에도 결과가 달라집니다.

    인터넷 없이 쓰기

    아이폰: 사파리에서 이 페이지를 연 뒤 공유 버튼 → "홈 화면에 추가". 한 번 설치하면 비행기 모드에서도 열립니다.
    안드로이드: 크롬 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치".
